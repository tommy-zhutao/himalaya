## Phase 3: 开发优先级

### 核心功能（MVP - 最小可行产品）

**高优先级（P0）- 必须完成**
- ✅ 项目基础结构
- ✅ PostgreSQL 数据库初始化
- ✅ News API Service（新闻列表、详情）
- ✅ Frontend - 新闻列表页面 + 翻页
- ✅ Frontend - 新闻详情页面
- ✅ RSS Fetcher Service（定时抓取）
- ✅ Frontend - 搜索功能 + 翻页
- ✅ 默认新闻源配置（20个中文源 + Hacker News）

**中优先级（P1）- 完成核心体验**
- ✅ User API Service（认证系统）
- ✅ Frontend - 登录/注册页面
- ✅ API Gateway（统一入口）
- ✅ Redis 缓存集成

**低优先级（P2）- 增强功能**
- ✅ AI Analysis Service（智能分析）
- ✅ 热点话题聚类
- ✅ 个性化推荐
- ✅ 用户收藏
- ✅ 用户设置
- ✅ 管理后台
- ✅ 分类筛选
- ✅ 相关新闻推荐
- ✅ 重复检测
- ✅ HTML Fetcher
- ✅ Content Fetcher
- ✅ API Fetcher
- ✅ Health Monitor
- ✅ Scheduler
